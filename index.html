Elasticsearch Component for Home-Assistant#

Publish Home Assistant events to your Elasticsearch cluster, and query them back into your automations!

Elasticsearch is a search and analytics engine for storing and exploring large amounts of data, and Kibana is its companion app for charts and dashboards. Sending your Home Assistant history there lets you keep it for as long as you choose, and analyze it across your whole home.

This integration sends entity state changes, not logs. To send your Home Assistant logs to the same cluster, use the companion Elastic Agent app.

Features#

  • Efficiently publishes Home-Assistant events to Elasticsearch using the Bulk API
  • Automatically sets up Datastreams using Time Series Data Streams ("TSDS") and Datastream Lifecycle Management ("DLM")
  • Supports Elastic's stack security features via optional username, password, and API keys
  • Selectively publish events based on labels, entities, devices, areas, or floors
  • Create query sensors with previews, independent polling, and source-data freshness checks
  • Run ES|QL queries from automations and scripts with the elasticsearch.query action
  • Pairs with the Elastic Agent app to ship Home Assistant Core, Supervisor, app, and host logs

Compatibility#

  • Elasticsearch 8.14+, including 9.x (Self, Cloud, or Serverless). Querying needs 8.19+, or 9.1+ on 9.x.
  • Elastic Common Schema version 1.0.0
  • Home Assistant Community Store
  • Home Assistant >= 2026.10

Older versions#

Version 1.0.0 includes support for 7.11 to 8.13. No features or bugfixes will be backported to this version. Version 0.4.0 includes support for versions of Elasticsearch older than 7.11. No features or bugfixes will be backported to this version.
